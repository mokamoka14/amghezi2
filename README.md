# amghezi2

یه گاو دارم به من شیر میده
صدای ماع‌ماع میده
بابام میره به بازار
میخره یک چمدان
از چمدان درمیاره
یه کفش و یک پیرهن
کفشو میده به پام
پیرهنو میده به تنم

مامان برام یه قند شکن خرید
از ته بازار خرید
وقتی میاد قند می‌شکنه
صدای قند، قند می‌کنه

بابام برام یه دفتر خرید
از ته بازار خرید
وقتی میاد مشق می‌نویسم
صدای آقا معلم میاد
میگه آفرین، آفرین
پسر (دختر) خوب و نازنین!
